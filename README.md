# 2D_Platformer
My first game for Unity game dev. Purpose for practicing and learning fundamental Game Dev skills

Game Idea Bank
1. Mobile Tower Defense Game

Common Components:
-Random components such as random spell that is cost-effective
-Cool monsters, heroes, towers
-Many modes - ultimate, campaign, etc.

Differentiation:
-The "Vampire Survivors" Roguelite Draft: Instead of just upgrading towers with gold between rounds, introduce a mid-wave leveling system. Every time the player kills enough monsters to fill an XP bar, the game pauses and offers three completely randomized, game-altering buffs or spells. This creates a highly satisfying, dopamine-driven "slot machine" feeling of rolling the exact perk needed to complete an overpowered build.
There will be two major options 
1. Upgrade the player himself
2. Unlock the towers and upgrade the towers

- "Auto-Battler" Merge & Evolve Mechanics: Rather than building specific towers from a menu, the player buys a "random tower spawn." Players can merge identical units into a higher-tier powerhouse, or mix different elements to unlock unpredictable, secret tower evolutions. This transforms the board into an active puzzle where the player is constantly chasing the visual and auditory climax of an evolution.
There will be some basic towers and advanced towers that can be created by merging the basic towers when unlocked.
